猫径 CatWay

地图应用 / Flutter + Node + MongoDB
关于

以地图点为单位归档到访记录。

一条记录绑定坐标、照片、当时写的攻略与到访次数；地图是入口，不是附加页。

客户端 Flutter，服务端 Node + MongoDB，部署于阿里云轻量服务器；管理端为独立脚本。

  • 地图：按点归档店 / 展 / 演出，配图与攻略同点存放
  • 内容：打卡、获赞、举报、定位与列表流
  • 界面：毛玻璃信息层，地图底图透出
  • 技术：Flutter 客户端 + Node + MongoDB
  • 部署：阿里云轻量服务器，nginx 反代，管理端独立脚本
  • 状态：v1.0.3，客户端已到可发布状态，未上线

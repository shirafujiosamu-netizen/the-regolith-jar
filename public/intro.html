欢迎页

实时星空与标题动效

背景取自 8796 颗恒星的真实星表。按浏览器定位得到的经纬度与当前时刻计算本地恒星时，将赤经赤纬换算成地平坐标后投影到全屏 canvas；换地点、换时间，头顶的星空随之改变。

  • 定位回退：拒绝授权或超时沿用默认坐标；页面隐藏时挂起绘制
  • 低开销：按星等筛选可见星，天球按分钟重算，漂移交给 CSS 合成层
  • 标题动效：主标题逐字淡入，字距从 .34em 收拢到 .16em，单次播放不循环
  • 金印：logo 为静态位图，只在悬停时放大 1.03 倍

自习室

音乐、计时、待办

左侧固定 400px 工具列，纵向排三张卡片；右侧是房间与聊天区，可整体隐藏进入单机模式。计时、待办、曲目与房间状态分别写入 `localStorage`，断线后本地部分仍可用。

  • 自习音乐：内置曲库 + 支持导入自己播放器的歌单（外链解析，不转存音频文件）
  • 同房间同步收听：房主切换曲目时，房间内其他成员同步跳转，进度对齐误差控制在 1 秒内
  • 番茄钟 / 正计时：25 分钟专注与 5 分钟休息可改，正计时用于不预设时长的场景，到点触发浏览器通知与提示音
  • 待办清单：回车新增、勾选完成，存本地；支持拖动排序
  • 自习室列表：`socket.io` 长连接，显示在线人数与各自累计时长，离开自动下线
  • IP 拉黑：房主可将指定 IP 移出房间，被拉黑后重连仍会被拒
  • 全屏单机模式：断开 socket，仅保留本地计时与待办，适合网络不稳时使用

情绪页

记录与放松

六张卡片共用一套可拖拽排序的网格：Pointer 按下后接管位移，占位块以 transform 让位，松手把新顺序写回 `localStorage`，刷新还原。记录类数据按日期分键，不上传服务器。

  • 卡片拖拽排序：Sortable 接管 pointer 事件，FLIP 计算落位；顺序、情绪、每日记录、待办分键存储，清空只作用于当前键
  • 呼吸练习：4-7-8 相位由 `requestAnimationFrame` 驱动圆形缩放；暂停保留相位与时间戳，恢复不跳帧
  • 环境声音：多轨 audio 各自持有 gain 与 loop，页面隐藏时挂起；音源走 CC0 外链，不转存文件
  • 解压游戏：canvas 点击消除，粒子与判定在单帧内完成，不落盘、不计分

实时星图

按定位算出的头顶星空

星表、观测点和时间三者决定画面。浏览器给出经纬度后（拒绝授权则回退默认坐标），用当前时刻的格林尼治恒星时把每颗星的赤经赤纬换算成地平坐标，只绘制地平线以上的部分。换城市、换时间，星座位置与可见星数都会变。

  • 定位与时间：`navigator.geolocation` → 本地恒星时 → 高度角 / 方位角；默认坐标上海
  • 星表：8796 颗恒星，按星等与色指数决定点的大小、亮度与色温；附带星座连线与中文星名
  • 渲染：Three.js 点云，天文位置按 4Hz 节流重算，`IntersectionObserver` 控制进入视口才绘制

作品卡片

Cover Flow 卡片带

页面左侧的一条横向卡片带，采用 Cover Flow 布局：中间卡片正面朝向镜头，两侧按距离递减缩放、增加旋转角与不透明度衰减。

  • 拖拽滑动：鼠标或触屏拖动，松手按惯性回弹到最近一张
  • 键盘操作：左右方向键切换，`Enter` 打开当前卡片
  • 跳转：带 `data-url` 的卡片可点击，其余停在原地
  • 移动端：卡片宽度与间距按视口宽度计算，保留 3D 纵深
  • 当前项目：THE REGOLITH JAR、Pico RamOS、巷、猫径 CatWay、OC 小工具、月壤箱
